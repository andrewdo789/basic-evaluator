# Coding, task 01: record store (progressive build, 4 levels, 90 minutes)

The format most often reported for the Anthropic Fellows online assessment (a CodeSignal-style build): one system, built
in four levels. Each level adds requirements; code that is easy to extend makes later levels faster.

**Placement:** levels 1-3 passing inside 90 minutes = coding level 7; all four in 90 minutes = level 9; all four in 75
minutes plus a passed live-coding mock = level 11 (see `skills.yaml`).

## Rules

- **Start the timer** when you open `level1.md`. Open `level2.md` only after level 1's tests pass, and so on.
- **No AI**, no autocomplete that writes code. Python docs are fine. Reading the test files is allowed (the real platform
  shows visible test inputs); say so in your result. Print-debugging only, no step debugger (the real IDE has none).
- Write your code in `solution.py`. Keep class and method names exactly as specified.
- Run from this folder: `python -m unittest tests.test_level1 -v`, then add `tests.test_level2`, and so on (re-run earlier
  levels with each new one). Standard library only.
